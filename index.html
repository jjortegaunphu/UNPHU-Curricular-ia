Perfil de Egreso AI

Perfil de egreso

Asiste en la elaboración y revisión del perfil de egreso de una carrera, asegurando una descripción integral del profesional que se pretende formar.

✓ Redacción recomendada entre 3 y 5 párrafos.
✓ Integra conocimientos, habilidades, destrezas, actitudes y valores.
✓ Revisa correspondencia con mercado laboral y tendencias del área de estudio.
✓ Verifica articulación con los objetivos de la carrera.
✓ Comprueba la relación Perfil → Competencias.
🎯

CompetenciasAI

Diseño de competencias

Genera, revisa y valida competencias vinculadas con el perfil de egreso y los criterios institucionales.

✓ Competencias Fundamentales, Genéricas y Especializadas.
✓ Protege las Competencias Fundamentales institucionales.
✓ Verbo en infinitivo + objeto de aprendizaje + condición/contexto + finalidad.
✓ Detecta competencias duplicadas o solapadas.
✓ Comprueba que sean observables y medibles.
✅

ResultadosAI

Resultados de Aprendizaje

Formula y revisa Resultados de Aprendizaje vinculados con las competencias y con los desempeños esperados al finalizar la asignatura.

✓ Verbo en infinitivo + objeto + contexto.
✓ Comprueba que sean observables y evaluables.
✓ Constructor guiado de RAE.
✓ Detecta redundancias entre resultados.
✓ Valida la relación Competencia → RAE.
📘

ProgramaAI

Programa de asignatura

Asiste en la elaboración y revisión integral del Programa de Asignatura.

✓ I. Datos Generales.
✓ II. Descripción de la Asignatura.
✓ III. Competencias.
✓ IV. Resultados de Aprendizaje.
✓ V. Contenidos.
✓ VI. Estrategias y Actividades Formativas.
✓ VII. Recursos didácticos e informacionales.
✓ VIII. Sistema de Evaluación del Aprendizaje.
📋

GuíaDocenteAI

Guía docente

Construye y revisa la planificación operativa de la asignatura, manteniendo coherencia con el Programa de Asignatura aprobado.

✓ VIII. Datos Generales.
✓ IX. Cronograma.
✓ X. Sistema de Evaluación.
✓ XI. Recursos Bibliográficos Actualizados.
✓ XII. Anexos.
✓ Revisión automática de alineación curricular semanal.
📊

EvaluaciónAI

Sistema de evaluación

Diseña y revisa el sistema de evaluación del aprendizaje desde un enfoque por competencias y resultados de aprendizaje.

✓ Evaluación diagnóstica, formativa y sumativa.
✓ Semana de aplicación.
✓ Técnica evaluativa.
✓ RAE asociado.
✓ Instrumento de evaluación.
✓ Valor o ponderación.
✓ Validación automática del total de 100 puntos.

Plataforma en desarrollo progresivo

Los módulos curriculares se incorporan de manera gradual. Perfil de Egreso AI ya dispone de las interfaces para creación y revisión. Los módulos de competencias, resultados de aprendizaje, programa de asignatura, guía docente y sistema de evaluación serán habilitados progresivamente.
